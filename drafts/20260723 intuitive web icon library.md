# vscode icon library

July 23, 2026

木

The official built-in icon library for Visual Studio Code is called **[Codicons](https://microsoft.github.io/vscode-codicons/dist/codicon.html)**. These are the core product icons used throughout the entire editor interface, including the sidebar, status bar, and panels. [link](https://code.visualstudio.com/api/references/icons-in-labels)

Depending on your specific goals, the term "icon library" can refer to a few different tools. Review the categories below to find exactly what you need.

### 💻 1. The Core VS Code Icon Font (For Extension Developers)

If you are building a VS Code extension or theme and want to reference the application's built-in vector graphics, you should use the default product library. [link](https://code.visualstudio.com/api/references/icons-in-labels)

- **[Codicons Repository](https://github.com/microsoft/vscode-codicons)**: The open-source home for the official icon font.
- **[Product Icon Reference](https://code.visualstudio.com/api/references/icons-in-labels)**: The official Microsoft documentation listing every single product icon ID (e.g., `$(pencil)` or `$(gear)`) to use inside extensions, hovers, or labels. [link](https://code.visualstudio.com/api/references/icons-in-labels)

### 📁 2. File and Folder Icon Packs (For the Sidebar Explorer)

If you want to change the icons displayed next to your files and directories in the code explorer tree, you can install these highly-rated icon themes from the marketplace: [link](https://code.visualstudio.com/api/references/icons-in-labels)

- **[Material Icon Theme](https://marketplace.visualstudio.com/items?itemName=PKief.material-icon-theme)**: The most popular pack, offering hundreds of clean, customizable Material Design file and folder graphics.
- **[vscode-icons](https://marketplace.visualstudio.com/items?itemName=vscode-icons-team.vscode-icons)**: A classic, massive library that features automatic project detection for frameworks like Angular and React.
- **[Symbols](https://marketplace.visualstudio.com/items?itemName=miguelsolorio.symbols)**: A modern, minimalist, sleek icon alternative designed by a Microsoft engineer. [link](https://marketplace.visualstudio.com/items?itemName=vscode-icons-team.vscode-icons)

### 🛠️ 3. Web Icon Libraries (In-Editor Search for Projects)

If you are looking for an extension that lets you search and insert frontend development icons (like FontAwesome or Lucide) directly into your HTML, React, or Vue code: [link](https://hugeicons.com/blog/development/top-vs-code-icon-extensions)

- **[Icons Library](https://marketplace.visualstudio.com/items?itemName=crsx.icons-library)**: Allows you to search and browse popular icon sets in one unified sidebar panel.
- **[Reicon](https://marketplace.visualstudio.com/items?itemName=DevChauhan.reicon)**: An open-source SVG icon library manager inside the editor that supports one-click copying for code markup. [link](https://marketplace.visualstudio.com/items?itemName=DevChauhan.reicon)
