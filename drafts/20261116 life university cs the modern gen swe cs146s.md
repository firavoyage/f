## **1. What does the course teach?**

The 2026 edition focuses on AI-native software engineering.

Major topics include:

| Topic                   | What you'll learn                                    |
| ----------------------- | ---------------------------------------------------- |
| Coding agents           | How Claude Code and other agents work                |
| Context engineering     | How to give AI the right context                     |
| MCP                     | Connecting AI agents to external tools               |
| Agent skills            | Giving agents reusable capabilities                  |
| Spec-driven development | Turning requirements into executable specifications  |
| Agentic code review     | Using AI to review code                              |
| AI testing & security   | Finding bugs and vulnerabilities                     |
| Software factories      | Building systems where humans and agents collaborate |

## **2. Why is this course interesting?**

Traditional software development:

1. Understand requirements.
2. Write code manually.
3. Debug.
4. Test.
5. Deploy.

AI-native software development:

1. Define what you want to build.
2. Give agents context and specifications.
3. Let agents implement features.
4. Review and test generated code.
5. Iterate with multiple agents and tools.
6. Deploy and monitor.

The important shift is from simply writing code to **orchestrating AI agents to build reliable software**.

## **4. Can you take it without attending Stanford?**

Yes, you can study the publicly available course materials independently. Stanford credit enrollment is a separate matter with academic prerequisites.

The 2026 course assumes programming experience equivalent to CS111/CS161, with CS221/CS229 recommended.&#x20;
