# how to select the video quality on ytdlp

By default, **`yt-dlp` automatically downloads the absolute highest quality** video and audio available and merges them together using [FFmpeg](https://github.com/yt-dlp/yt-dlp).

However, you can easily control and select specific video qualities using either **Format Selection** (e.g., `-f`) or **Sorting Filters** (e.g., `-S`). [link](https://www.youtube.com/watch?v=3tbWHvq7MUc\&t=18)

***

### Method 1: The Quick Filter Method (Easiest)

If you want to cap the maximum resolution without hunting down specific stream IDs, use the `-S` (format sorting) flag. This tells `yt-dlp` to fetch the best possible quality _up to_ your specified resolution. [link](https://www.youtube.com/watch?v=05g%5F7daZixo\&t=5)

- **For 1080p maximum:**\
  bash

<!---->

```
yt-dlp -S "res:1080" "YOUR_URL"
```

Use code with caution.

- **For 720p maximum** (great for saving data or older hardware):\
  bash

<!---->

```
yt-dlp -S "res:720" "YOUR_URL"
```

Use code with caution.

- **For 4K maximum:**\
  bash

<!---->

```
yt-dlp -S "res:2160" "YOUR_URL"
```

Use code with caution.\
[link](https://askubuntu.com/questions/486297/how-to-select-video-quality-from-youtube-dl)

***

### Method 2: The Exact Format Code Method (Most Control)

Modern video sites host video and audio as separate tracks. To pick the exact combination you want, you must list the tracks and select them by their ID. [link](https://www.youtube.com/watch?v=3tbWHvq7MUc\&t=18)

1. **List all available formats:**\
   Run the command with a capital `-F`:\
   bash

<!---->

```
yt-dlp -F "YOUR_URL"
```

Use code with caution.\
_This will print a table showing columns like `ID`, `EXT`, `RESOLUTION`, and `FILESIZE`._
2\. **Download using the ID codes:**\
Locate the ID number for your preferred video stream (e.g., `399` for 1080p) and your preferred audio stream (e.g., `140` for high-quality audio). Download them together using a lowercase `-f` and a `+` sign:\
bash

```
yt-dlp -f 399+140 "YOUR_URL"
```

Use code with caution.\
[link](https://www.youtube.com/watch?v=3tbWHvq7MUc\&t=18)

***

### Method 3: Advanced Conditional Quality Selectors

If you want to create a permanent rule (for instance, in a custom script or configuration file), you can use explicit advanced arguments. [link](https://stackoverflow.com/questions/69517841/how-to-set-youtube-dl-python-to-always-pick-1080p)

- **Download the best video that is exactly 1080p (or lower) combined with best audio:**\
  bash

<!---->

```
yt-dlp -f "bestvideo[height<=1080]+bestaudio/best" "YOUR_URL"
```

Use code with caution.

- **Force a specific format container (like MP4)** while keeping a resolution limit:\
  bash

<!---->

```
yt-dlp -f "bestvideo[height<=720][ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best" "YOUR_URL"
```

Use code with caution.

***

### ⚠️ Crucial Requirement

To successfully merge high-quality video and separate audio tracks into a single file, you **must have FFmpeg installed on your system**. Without FFmpeg, `yt-dlp` will be forced to fallback to pre-merged formats, which usually cap out at a much lower 720p quality. [link](https://askubuntu.com/questions/486297/how-to-select-video-quality-from-youtube-dl)
