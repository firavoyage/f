## what does it mean

This quote describes the two main ways programmers name functions based on **what the function does** or **what the function returns**. It means that a good function name tells you its purpose at a glance, usually falling into one of two categories:

### 1. Naming by Action (Operations)

These names use **verbs** because the function performs a specific action on the data you give it.

- `print(x)` → "Hey computer, **print** this variable."
- `add(x, y)` → "Hey computer, **add** these numbers together."

### 2. Naming by Output (Resulting Quantities)

These names use **nouns or descriptors** because the function calculates and returns a specific value. The name tells you exactly what the final result represents.

- `max(x, y)` → The result is the **maximum** value.
- `abs(x)` → The result is the **absolute** value.

### Summary Comparison

| Naming Style  | Part of Speech   | Focus                             | Example                            |
| ------------- | ---------------- | --------------------------------- | ---------------------------------- |
| **Operation** | Verb             | The process or action being taken | `save_file()`, `calculate_total()` |
| **Quantity**  | Noun / Adjective | The final value you get back      | `file_size`, `total_price`         |

In short, it means a function's name should either say **what it is doing** or **what it is making**.

## why is it called quantity

In computer science and mathematics, it is called a **quantity** <mark>because the function's primary job is to calculate and return a<span> </span><strong>measurable value, amount, or specific property</strong></mark>.

Instead of focusing on the _action_ it took to get there, the name focuses entirely on the _final data point_ you receive.

Here is why that word fits so well:

- **It represents a value:** When you call `max(5, 10)`, you aren't thinking about the step-by-step sorting process the computer does. You just want the resulting value: `10`.
- **It answers "How much?" or "What is it?":** Functions named after quantities act like labels for the answer. For example, `len("hello")` results in the quantity of characters (`5`).
- **It acts like a mathematical property:** In math, we talk about the "absolute value" or the "sum" as quantities. Programming borrows this language because these functions behave exactly like mathematical operations that yield a result.
