# py decorator

## py decorator

A **decorator** in Python is a function that wraps another function to add behavior without changing the original function’s code.

```python
from functools import wraps

def log_call(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log_call
def greet(name):
    return f"Hello, {name}!"

print(greet("Sam"))
```

`@log_call` is shorthand for:

```python
greet = log_call(greet)
```

Use `*args` and `**kwargs` so the decorator works with functions that accept different arguments. `@wraps(func)` preserves the original function’s name and documentation.

## examples

Here are a few common Python decorator examples.

### 1. Log each function call

```python
from functools import wraps

def log_call(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log_call
def greet(name):
    return f"Hello, {name}!"

print(greet("Mia"))
```

Output:

```text
Calling greet
Hello, Mia!
```

### 2. Measure execution time

```python
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"{func.__name__} took {elapsed:.3f} seconds")
        return result
    return wrapper

@timer
def wait_a_bit():
    time.sleep(0.5)

wait_a_bit()
```

### 3. Decorator with an argument

This decorator repeats a function a chosen number of times:

```python
from functools import wraps

def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def say_hi():
    print("Hi!")

say_hi()
```

### 4. Check a condition before running

```python
from functools import wraps

def require_admin(func):
    @wraps(func)
    def wrapper(user, *args, **kwargs):
        if not user.get("is_admin"):
            raise PermissionError("Admin access required")
        return func(user, *args, **kwargs)
    return wrapper

@require_admin
def delete_record(user, record_id):
    return f"Deleted record {record_id}"

admin = {"is_admin": True}
print(delete_record(admin, 42))
```

The `@decorator` syntax is shorthand for:

```python
function = decorator(function)
```

## why functools wraps

`@wraps(func)` preserves the original function’s metadata when a decorator replaces it with a wrapper.

Without `wraps`, the decorated function looks like the wrapper:

```python
def decorator(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@decorator
def greet(name):
    """Greet someone."""
    return f"Hello, {name}!"

print(greet.__name__)  # wrapper
print(greet.__doc__)   # None
```

With `@wraps`, the original name and docstring are retained:

```python
from functools import wraps

def decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@decorator
def greet(name):
    """Greet someone."""
    return f"Hello, {name}!"

print(greet.__name__)  # greet
print(greet.__doc__)   # Greet someone.
```

This helps debugging, documentation tools, and introspection behave as expected.

## can it be expected to show up as the wrapper instead

Yes. A decorated function is replaced by the wrapper, so you *can* expect its actual callable to be the wrapper.

`functools.wraps` doesn’t change that—it copies metadata like `__name__` and `__doc__` from the original function onto the wrapper. Without it, the function is still the wrapper, but it reports its name as `"wrapper"`.

For example:

```python
def decorator(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@decorator
def greet():
    pass

print(greet.__name__)  # wrapper
```

Use `@wraps(func)` when you want the decorated function to *appear* as the original function for debugging and introspection. Omit it if you specifically want it to appear as `"wrapper"`—though it’s usually better to preserve the original metadata.
