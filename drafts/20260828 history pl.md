# the history of programming lang

The history of programming languages <mark>tracks a continuous shift<span> </span><strong>from hardware-focused instruction to abstract, human-readable code</strong></mark>. This evolution spans nearly two centuries, transforming how humans interact with computing machines. [link](https://en.wikipedia.org/wiki/History%5Fof%5Fprogramming%5Flanguages)

***

### 1. Laying the Foundations (1840s–1940s)

Before modern hardware existed, mathematicians defined the core theory of computation. [link](https://www.youtube.com/watch?v=K5yv7dY17EA)

- **1843**: [Ada Lovelace](https://www.britannica.com/story/ada-lovelace-the-first-computer-programmer) writes the first machine algorithm for [Charles Babbage’s](https://www.hp.com/gb-en/tech-takes/desktops/explainer/computer-history-programming-languages.html) mechanical Analytical Engine, earning recognition as the world's first programmer.
- **1942–1945**: Konrad Zuse develops **Plankalkül**, the earliest high-level algorithmic language, though it remains unimplemented for decades.
- **1949**: **Assembly Language** emerges, using short mnemonic words to replace raw binary machine code (1s and 0s). [link](https://praxent.com/blog/history-of-programming-languages)

***

### 2. The Rise of High-Level Languages (1950s–1960s)

The introduction of compilers allowed programmers to write code using English-like syntax, which was then automatically converted into machine code. [link](https://www.youtube.com/watch?v=9uW6B9LPntY\&t=60)

- **1957 (FORTRAN)**: Developed by John Backus at [IBM](https://en.wikipedia.org/wiki/History%5Fof%5Fprogramming%5Flanguages), it optimizes complex scientific and mathematical calculations.
- **1958 (ALGOL)**: Serves as the structural blueprint for many modern imperative languages.
- **1959 (LISP)**: Created by John McCarthy, introducing functional programming and automated garbage collection.
- **1959 (COBOL)**: Designed under Grace Hopper to bring standard English syntax to corporate business and banking software.
- **1964 (BASIC)**: Developed at [Dartmouth College](https://medium.com/@josueparra2892/the-origin-of-programming-languages-a-journey-through-history-91c6ed30a8a8) to lower the barrier to entry, bringing programming to general students. [link](https://www.hp.com/gb-en/tech-takes/desktops/explainer/computer-history-programming-languages.html)

***

### 3. Efficiency, Structure, and Systems (1970s–1980s)

This era brought standard structures to data storage and introduced Object-Oriented Programming (OOP) to handle expanding software complexity. [link](https://www.youtube.com/watch?v=YZV8Zv%5FYW7I)

- **1972 (C)**: Dennis Ritchie creates C at Bell Labs to write the Unix operating systems. It offers low-level hardware control combined with high-level efficiency. [link](https://www.cs.odu.edu/~zeil/cs355/s25/Public/history/index.html)
- **1972 (SQL)**: Built by IBM researchers to efficiently query and manage data inside relational databases. [link](https://skillpanel.com/blog/history-of-programming-languages/)
- **1983 (C++)**: Bjarne Stroustrup adds classes and object orientation to C, enabling developers to build large-scale application frameworks. [link](https://edtechmagazine.com/higher/article/2013/04/brief-history-computer-programming-languages-infographic)

***

### 4. The Internet Era and Scripting (1990s)

The rise of personal computers and the World Wide Web demanded rapid development speeds, platform independence, and internet-native integrations. [link](https://bytebytego.com/guides/a-brief-history-og-programming-languages/)

- **1991 (Python)**: Guido van Rossum emphasizes developer readability and code simplicity over runtime speed.
- **1995 (Java)**: Introduced with a "Write Once, Run Anywhere" philosophy, utilizing a virtual machine to run across different hardware platforms.
- **1995 (JavaScript)**: Developed to run inside web browsers, quickly expanding to control the client side of web applications. [link](https://medium.com/codex/a-basic-history-of-programming-languages-and-how-to-write-your-own-c05b804dd932)

***

### 5. Modern Specialization (2000s–Present)

Modern engineering focuses on safe concurrency, high performance, type safety, and massive cloud infrastructure. [link](https://www.youtube.com/shorts/0mrfT1TKMTA)

| Language        | Launch Year | Primary Focus / Paradigm                                        |
| --------------- | ----------- | --------------------------------------------------------------- |
| **C#**          | 2000        | Enterprise software, desktop apps, and gaming.                  |
| **Go (Golang)** | 2009        | Highly concurrent, scalable cloud backend systems.              |
| **Rust**        | 2010        | Memory-safe systems programming without a garbage collector.    |
| **Kotlin**      | 2011        | Modern, concise application code; now the standard for Android. |
| **Swift**       | 2014        | Apple ecosystem application development, replacing Objective-C. |

# the history of pascal

The <mark><strong>Pascal programming language was developed by Swiss computer scientist Niklaus Wirth</strong><span> </span>between 1968 and 1969, and officially published in 1970</mark>. Named in honor of the 17th-century French mathematician and philosopher Blaise Pascal, it was designed as a small, efficient language intended to encourage good programming practices using structured programming and data structuring.

### ⏳ Chronological History

```
[1968-1969]  ──>  [1970]  ──>  [1972]  ──>  [1977]  ──>  [1983]  ──>  [1995]
Developed         Published    CDC 6000     UCSD         Turbo        Delphi
by Wirth                       Compiler     Pascal       Pascal       Released
```

- **1968–1969 (Inception):** Niklaus Wirth designed Pascal as a successor to ALGOL 60, aiming to create a language suitable for teaching structured programming.
- **1970 (Official Release):** The language definition was officially published.
- **1972 (First Compiler):** The first compiler was written in Pascal itself for the CDC 6000 mainframe series, proving the language's self-hosting capability.
- **1977 (Portability Milestone):** UCSD Pascal was released, introducing the "P-code machine" concept. This allowed programs to run on various microcomputers by compiling to intermediate code.
- **1983 (The Turbo Era):** Borland released **Turbo Pascal** for DOS, which revolutionized software development with its lightning-fast compilation speeds and low price point.
- **1995 (Transition to Object-Oriented):** Borland launched **Delphi**, an evolution of Object Pascal, turning it into a premier rapid application development (RAD) tool for Windows.

### 🎯 Key Design Goals

Wirth created Pascal to solve specific limitations found in early languages like FORTRAN and COBOL:

- **Teaching Structured Programming:** It forced clean execution paths using `IF`, `THEN`, `ELSE`, `WHILE`, and `REPEAT` blocks instead of disorganized `GOTO` statements.
- **Strong Type Checking:** The language enforced strict variable definitions to catch errors during compilation rather than at runtime.
- **Data Structuring:** It introduced advanced concepts like user-defined records, enumerations, sets, and dynamic pointers.

### 📈 Evolution and Variants

As Pascal grew, it spawned several highly influential versions and dialects:

- **Standard Pascal:** Defined by ISO 7185 in 1983 to standardize the base language features across different computer hardware systems.
- **Concurrent Pascal:** Created by Per Brinch Hansen in 1975 to support concurrent programming via monitors and processes.
- **Object Pascal:** Developed by Apple in 1985 (with consultation from Wirth) to bring object-oriented programming to the Macintosh platform.
- **Free Pascal & Lazarus:** Modern, open-source implementations created to keep Pascal viable across contemporary operating systems like Linux, macOS, and Windows.

### 🏛️ Historical Legacy

While mainstream commercial development shifted toward C, C++, and Java in the late 1990s, Pascal left a permanent mark on computing. It served as the primary teaching language in computer science universities for over two decades, trained a generation of software engineers, and directly inspired modern languages like **Ada** and **Go**.
